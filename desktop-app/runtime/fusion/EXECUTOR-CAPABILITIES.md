# 工部执行能力边界

工部模型是文本生成器。它返回相对路径与 UTF-8 文本内容，由可信 runtime 校验并写入
本次执行目录。模型本身没有文件系统工具、网络工具或命令执行工具。

## 能做什么

- 生成文本文件，以及对生成内容的报告。多子任务各有独立输出目录。
- 阅读操作者通过 CLI `--input` 显式提供、经允许目录和大小检查后的源文件文本。
- 使用 `prior_outputs` 中的先前子任务结果。
- 从 `input.runtime.now` 取得本次调用的本地时间，从 `runtime.workspace` 了解输出位置。

## 不能做什么

- 联网、访问外部服务、执行 shell 或其他系统命令。
- 读取任意路径；知道绝对 workspace 路径不代表拥有读取权限。
- 自行获取系统时间或持续观察时钟；时间只能取 `runtime.now`。
- 采购、获取密钥、更改配置、授权或绕过预算、租约和签批处审批。

缺能力时必须明确说“缺什么”，不许编造时间、输入内容、执行结果或验证证据。
例如没有 sources 时，应说明缺少操作者提供的源文件；不得声称已经读取某个路径。
当前日期任务使用 `runtime.now`，不得留下 `YYYY-MM-DD` 占位符或猜测日期。

## runtime 契约

工部每次调用收到 `now`（带偏移的 ISO 8601 本地时间）、`timezone`（本地时区名称或
缩写）、`workspace`（绝对输出目录）、`role: gongbu` 和
`limits: {max_file_bytes: 262144, no_network: true, no_commands: true}`。
`max_file_bytes` 是上下文上界，不扩大现有 schema：当前每份文件内容仍最多 12000
字符、每次最多 4 份，路径和总请求大小检查仍然生效。
中书、门下、尚书仅收到 `now` 和实例 `workspace`。runtime 不包含密钥或环境变量集合。

以上字段是上下文，不是工具或额外授权。
